# KESHIYON — Google Sheets 対戦記録対応版

GitHub Pagesで動く静的ブラウザ版に、Googleスプレッドシートへの「勝敗確定対局」記録機能を追加したパッケージです。

## 保存されるデータ

- 勝敗が確定した対局のみ保存します。途中で新しいゲームを開始した未完了の対局は保存しません。
- 引き分けは「勝敗が付く試合のみ」という条件に合わせて保存対象外です。
- サーバー側（Apps Script）で着手列を順番に再生し、合法手・終局・最終得点が一致することを検証してから記録します。
- 全訪問者の記録は、サイト管理者が設定した同じスプレッドシートに集約されます。
- プレイヤー名、メールアドレス、IPアドレス、Googleアカウントなどは収集しません。

シートの列は「記録日時（サーバー） / 対局ID / 勝者 / ○得点 / ×得点 / 手数 / ○側の設定 / ×側の設定 / 着手列・行（JSON） / 検証バージョン」です。AI対戦も、結果が確定し勝敗が付いたものは記録対象です。

## 1. Googleスプレッドシートを作る

1. Googleスプレッドシートを新規作成します。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. エディタの `Code.gs` の内容を、このZIP内の `google-apps-script/Code.gs` の内容で置き換えます。
4. 保存して、関数一覧から `setupSheet` を選び **実行** します。
5. 初回はGoogleの認証を許可します。元のスプレッドシートに `対戦記録` シートとヘッダーが作成されます。

## 2. Apps ScriptをWebアプリとして公開

1. Apps Script画面の **デプロイ → 新しいデプロイ** を開きます。
2. 種類を **ウェブアプリ** にします。
3. 実行ユーザーを **自分** にします。
4. アクセスできるユーザーを **全員** にします（Google Workspaceの管理者設定で制限されている場合は公開できないことがあります）。
5. デプロイし、表示されたWebアプリURL（通常 `https://script.google.com/macros/s/.../exec`）をコピーします。

この公開URLは書き込み用のエンドポイントです。スプレッドシート自体を一般公開する必要はありません。シートの共有設定は非公開のままにしてください。

## 3. URLをGitHub Pages版に設定

1. `app.js` をテキストエディタで開きます。
2. 先頭付近にある次の行を探します。

```js
const SHEETS_ENDPOINT = '';
```

3. 空文字の中に、手順2でコピーしたWebアプリURLを貼ります。例：

```js
const SHEETS_ENDPOINT = 'https://script.google.com/macros/s/ここにデプロイID/exec';
```

4. 以下のブラウザ版ファイルをGitHub Pagesの公開フォルダへアップロードし、既存ファイルを上書きします。
   - `index.html`
   - `style.css`
   - `app.js`
   - `game.js`
   - `ai.js`
   - `ai-worker.js`

`google-apps-script` フォルダはGitHub Pagesにアップロードする必要はありません。これはApps Scriptエディタへコピーするサーバー側コードです。

## 4. 動作確認

1. 公開済みGitHub PagesをHTTPSで開きます。
2. 対局を最後まで進め、○または×の勝利で終局させます。
3. スプレッドシートの `対戦記録` シートに行が追加されたか確認します。
4. 引き分けや途中終了では行が追加されません。

ブラウザの `no-cors` 制約のため、画面では送信要求を出したことまで表示し、スプレッドシートへの書き込み成功を直接確認することはできません。最初のテスト対局後はシートを開いて保存結果を確認してください。

## 無料利用・セキュリティ上の注意

- GitHub Pages、Googleスプレッドシート、Apps Scriptの通常利用範囲内で構成できます。別途サーバーの契約や支払い情報の登録は不要な構成ですが、各サービスの無料利用枠・実行クォータ・Googleアカウントのポリシーに従います。無制限利用を保証するものではありません。
- エンドポイントは公開URLなので、誰でもアクセスできます。Apps Script側で合法な完了対局の再生検証、重複IDチェック、簡易的な送信頻度制限をしていますが、公開エンドポイントへの大量アクセスを完全には防げません。
- 記録シートは非公開のままにしてください。サイト上にはAPIキーやスプレッドシートIDなどの秘密情報を置かず、Apps ScriptのWebアプリURL以外の秘密はフロントエンドに含めないでください。
- WebアプリURLを変更・再デプロイしたときは、`app.js` のURLも更新してください。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン・スマホ対応・保存ステータス表示
- `app.js` — ブラウザのゲーム処理と、終局時の記録送信
- `game.js` — ゲームルール
- `ai.js` — ブラウザ内ローカルAI
- `ai-worker.js` — AI探索用Web Worker
- `google-apps-script/Code.gs` — スプレッドシート側で検証・保存するコード
